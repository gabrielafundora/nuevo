ℹ️ ¿Cómo obtener el archivo?
  1. Ingresa a kdpreports.amazon.com
  2. Selecciona «Ventas y regalías» (o «Sales & Royalties»)
  3. Filtra por período
  4. Haz clic en Descargar reporte
  5. Sube el archivo .xlsx o .csv aquí

Información sobre Amazon KDP

Amazon KDP no ofrece una API pública para acceder a datos de ventas directamente. La única forma oficial y compatible con los términos de servicio es descargar los reportes desde el panel de KDP e importarlos aquí.

Se aceptan tanto el formato Excel (.xlsx) descargado desde la interfaz en español como el formato CSV de la interfaz en inglés. Una vez importados, los datos se integran con el catálogo, el inventario y el sistema de regalías automáticamente.
