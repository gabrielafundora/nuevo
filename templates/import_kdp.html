ℹ️ ¿Cómo obtener el CSV?
  1. Ingresa a kdpreports.amazon.com
  2. Selecciona «Sales & Royalties»
  3. Filtra por marketplace, período, etc.
  4. Haz clic en Download report
  5. Sube el archivo .csv aquí

Información sobre Amazon KDP

Amazon KDP no ofrece una API pública para acceder a datos de ventas directamente. La única forma oficial y compatible con los términos de servicio es descargar los reportes CSV desde el panel de KDP e importarlos aquí.

Una vez importados, los datos se integran con el catálogo, el inventario digital y el sistema de regalías automáticamente.
